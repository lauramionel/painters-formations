# formations

ten painters, each one moves and sounds different. click anywhere to interact.

**[live](https://lauramionel.github.io/painters-formations/)**

each preset is a palette, a particle shape, a motion engine, and a procedural tone.js voice tuned to that painter's feel. ten so far: van gogh, monet, mondrian, pollock, klimt, schiele, matisse, kandinsky, frida kahlo, dalí.

## controls

click drops a vortex (also triggers a chord). drag to stir. ◀▶ or arrow keys to switch painters. M toggles sound (audio inits on first click, browser policy). F fullscreen, H hide ui, R reset.

## stack

one html file, no build. p5.js for canvas, tone.js for audio.

```
git clone https://github.com/lauramionel/painters-formations
cd painters-formations
open index.html
```
