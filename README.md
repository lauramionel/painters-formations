# formations

ten painters, each one moves differently. click anywhere to interact.

**[live](https://lauramionel.github.io/painters-formations/)**

each preset is a palette, a particle shape, and a motion engine tuned to that painter's feel. ten so far: van gogh, monet, mondrian, pollock, klimt, schiele, matisse, kandinsky, frida kahlo, dalí.

## controls

click drops a vortex. drag to stir. ◀▶ or arrow keys to switch painters. F fullscreen, H hide ui, R reset.

## stack

one html file, no build. p5.js for canvas.

```
git clone https://github.com/lauramionel/painters-formations
cd painters-formations
open index.html
```
